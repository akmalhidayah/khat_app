02 · Perhitungan Class Weight

Rumus balanced weight: wi = N / (K × ni), dengan N = {{ dataset_totals.train }} (total train), K = {{ num_classes }} kelas, ni = jumlah sampel train kelas i. Bobot lebih besar diberikan ke kelas minoritas.

{# ── 05 Dimensi Konvolusi ── #}

05 · Perhitungan Dimensi Feature Map VGG16

Setiap blok konvolusi VGG16 mempertahankan ukuran spatial dengan padding same, lalu MaxPool 2×2 memperkecil H dan W menjadi setengahnya. Rumus umum setelah MaxPool: Hout = Hin / 2.

{% for row in spatial_dimensions %} {% endfor %}
Blok Operasi Perhitungan Ukuran Output Shape
{{ row.block }} {{ row.operation }} {{ row.formula }} {{ row.output }}

Conv3×3 dengan padding same: output spatial = input spatial. Jumlah parameter conv layer ≈ (k² × C_in × C_out) + C_out, dengan k=3.
