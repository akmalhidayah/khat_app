ConditionKnown Class Status

{# 13. Decision logic #}
13

Logika Keputusan Akhir

Keputusan akhir bukan hanya “benar/salah” — sistem memberi label yang memberi tahu apakah hasil boleh dipakai langsung, perlu hati-hati, atau wajib direview manusia.

KeputusanAturan (kapan muncul)
DiterimaPrediksi cocok dengan label pembanding + Confidence ≥ 85% + Margin ≥ 15%
Diterima dengan CatatanTidak ada label pembanding, confidence sedang/kuat
Review OpsionalConfidence sedang, tidak ada mismatch
Review Manual DisarankanConfidence lemah atau sumber eksternal tanpa label
Review Manual WajibPrediksi ≠ label pembanding, confidence rendah, atau kelas ragu
Ditolak Non-KhatTahap 1 mendeteksi bukan kaligrafi Khat

{# 20. Thesis interpretation #}
20

Interpretasi Akademik untuk Penelitian Skripsi

Sistem klasifikasi Khat Arab menggunakan model citra berbasis Convolutional Neural Network (CNN) dengan arsitektur {{ model_info.architecture_label or model_info.source }} ({% if model_info.is_teachable_machine %}TensorFlow.js / Teachable Machine{% else %}TensorFlow / Keras transfer learning{% endif %}). Dataset penelitian terdiri dari {{ ds.processed_total or sm.processed or ds.total_raw }} citra ({{ ds.per_class|length }} kelas, masing-masing {{ (ds.total_raw // (ds.per_class|length)) if ds.total_raw and ds.per_class else '—' }} citra per kelas pada folder raw), dibagi menjadi data latih {{ ds.train_data_count or sm.train_data_count or (ds.train_count + ds.validation_count) }} ({{ ds.train_data_pct or sm.train_data_pct }}%) dan holdout test {{ ds.test_count or sm.test_count }} ({{ ds.test_data_pct or sm.test_data_pct }}%). Citra masukan diproses menjadi ukuran 224 × 224 piksel dengan {{ model_info.preprocessing }}, kemudian model menghasilkan distribusi probabilitas untuk empat kelas khat: {% for label in model_info.labels %}{{ label }}{% if not loop.last %}, {% endif %}{% endfor %}.

Kelas dengan probabilitas tertinggi (argmax) ditetapkan sebagai prediksi utama. Untuk meningkatkan validitas hasil, sistem tidak hanya menampilkan kelas prediksi, tetapi juga menghitung confidence (probabilitas Top-1), margin Top-2 (selisih dua probabilitas tertinggi), status validasi label pembanding (expected class), serta keputusan akhir seperti Accepted, Accepted with Caution, atau Manual Review Required.

Evaluasi model dilakukan pada holdout test set sebanyak {{ ev.test_samples or sm.test_count or '—' }} citra dengan akurasi {{ ev.accuracy_pct or '—' }}{% if ev.accuracy_pct %}%{% endif %}, presisi weighted {{ ev.precision_pct or '—' }}{% if ev.precision_pct %}%{% endif %}, recall weighted {{ ev.recall_pct or '—' }}{% if ev.recall_pct %}%{% endif %}, dan F1-score weighted {{ ev.f1_pct or '—' }}{% if ev.f1_pct %}%{% endif %}. Confusion matrix dan analisis pasangan error digunakan untuk mengidentifikasi kelas yang sering tertukar. Temuan ini mendukung pembahasan metodologi dan hasil penelitian skripsi terkait kinerja model, kualitas dataset, dan interpretabilitas keputusan algoritma.

{# 21. Limitations #}
21

Catatan Batasan Sistem

  • Sistem hanya mengenali empat kelas terlatih.
  • Citra di luar kelas terlatih dapat dipaksa ke kelas terdekat (forced prediction).
  • Confidence tinggi tidak selalu berarti prediksi benar — label salah atau overlap visual tetap mungkin.
  • Ketidakseimbangan dataset dapat memengaruhi distribusi probabilitas.
  • {% if model_info.is_teachable_machine %}Teachable Machine tidak mengekspos perhitungan internal layer-by-layer di aplikasi ini.{% else %}Detail perhitungan internal layer EfficientNetB0 tidak ditampilkan di aplikasi ini — hanya output softmax dan metrik evaluasi.{% endif %}
  • Review manual tetap diperlukan untuk prediksi ambigu atau mismatch label.
